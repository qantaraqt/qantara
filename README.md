# qantara

> a ponte entre tecnologia e possibilidades

Site institucional — Astro 5 + Tailwind v4.

## dev

```bash
npm install
npm run dev
```

Abre http://localhost:4321

## build

```bash
npm run build
```

Output em `dist/` — static HTML pronto para CDN.

## deploy

Deploy estático em DigitalOcean App Platform (ver `.do/app.yaml`).

## stack

- Astro 5 (static)
- Tailwind v4 via `@tailwindcss/vite`
- Bricolage Grotesque · Satoshi · JetBrains Mono (Fontshare)
